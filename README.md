📦 QR Code Component
🧾 Description
A simple and responsive QR code card built using HTML and CSS. This project is part of the Frontend Mentor challenges and focuses on layout, typography, and responsiveness.

🎯 Objectives
Practice using CSS Grid for centering content.

Apply responsive design techniques for mobile screens.

Use Google Fonts (Outfit) with weights 400 and 700.

Improve semantic HTML and visual hierarchy.
